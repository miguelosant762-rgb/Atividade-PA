# Pedra, Papel e Tesoura

O projeto **Pedra, Papel e Tesoura** é um jogo interativo desenvolvido para proporcionar diversão e entretenimento ao usuário. Nele, o jogador pode escolher entre três opções: pedra, papel ou tesoura, competindo contra o computador, que realiza suas escolhas de forma aleatória.

Após cada jogada, o sistema compara as escolhas e apresenta o resultado, informando se o jogador venceu, perdeu ou empatou.

**Tecnologias utilizadas:**

- HTML: estrutura da página.
- CSS: estilização, cores, organização e aparência visual.
- JavaScript: funcionamento do jogo, escolhas aleatórias e identificação dos resultados.

**Como executar o projeto:**

1. Baixe os arquivos do projeto.
2. Coloque os arquivos `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.
4. Escolha entre Pedra, Papel ou Tesoura para jogar contra o computador.
